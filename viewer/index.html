서재 파일 구글 드라이브에 백업하기

서재의 PDF를 내 드라이브의 '늘뷰어 책장' 폴더에 보통 PDF 파일로 백업합니다. 브라우저 데이터를 지워도 파일이 남고, 드라이브에서 직접 열 수 있습니다. 필기는 포함되지 않습니다(필기는 '기기간 서재 동기화'가 보관). 동기화와는 별도로 구글 권한 허용 창이 한 번 뜰 수 있습니다.
