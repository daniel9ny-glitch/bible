패드·PC처럼 여러 기기에서 같은 서재를 쓰도록 목록·필기·북마크를 맞춥니다. 파일은 드라이브의 앱 전용 숨김 폴더에 저장됩니다.

연결 상태
동기화 범위
도움말
무엇이 동기화되나요
  • 문서 목록, 분류, 제목, 즐겨찾기
  • 필기, 북마크, 마지막으로 읽은 쪽
  • PDF 원본 (위 스위치를 켠 경우)

확대·보기 방식 같은 화면 설정은 기기마다 따로 둡니다. 같은 문서를 두 기기에서 따로 고치면 필기와 북마크는 합쳐지고, 제목 같은 항목은 나중에 바꾼 쪽이 남습니다.

문제가 생겼을 때

두 방법 모두 이 기기의 문서는 지우지 않습니다. 먼저 ①을 써 보고, 그래도 이상하면 ②를 쓰세요.

서재 파일 구글 드라이브에 백업하기

서재의 PDF를 내 드라이브의 '늘뷰어 책장' 폴더에 보통 PDF 파일로 백업합니다. 브라우저 데이터를 지워도 파일이 남고, 드라이브에서 직접 열 수 있습니다. 필기는 포함되지 않습니다(필기는 '기기간 서재 동기화'가 보관). 동기화와는 별도로 구글 권한 허용 창이 한 번 뜰 수 있습니다.

백업 (서재 → 드라이브)
바뀐 것만 올립니다. 서재에 없는 파일은 확인 후 드라이브 휴지통으로 옮깁니다.
