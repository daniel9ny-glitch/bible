구글 드라이브 동기화

  • 문서 목록, 분류, 제목, 즐겨찾기
  • 필기, 북마크, 마지막으로 읽은 쪽
  • PDF 원본 (위 스위치를 켠 경우)

확대·보기 방식 같은 화면 설정은 기기마다 따로 둡니다. 파일은 드라이브의 앱 전용 폴더에 저장되어 드라이브 화면에는 보이지 않습니다. 같은 문서를 두 기기에서 따로 고치면 필기와 북마크는 합쳐지고, 제목 같은 항목은 나중에 바꾼 쪽이 남습니다.
