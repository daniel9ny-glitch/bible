# 늘뷰어 저장 키 목록

브라우저 `localStorage`에 `neul-`로 시작하는 이름으로 저장되는 값입니다. 앱 코드(`index.html`)를 보고 정리했고, 값의 뜻이 코드에서 바로 확인되지 않은 것은 "확인 필요"로 적었습니다.
문서·필기·표지 본체는 이 목록이 아니라 IndexedDB(`neul-viewer`)에 있습니다.

## 1. 기기 간에 맞춰지는 설정 (드라이브 동기화 때 가장 최근에 바꾼 값으로 통일)
코드의 `setSyncKey` 정규식에 들어 있는 것만 해당합니다. 바꾼 시각은 `neul-setst`에 따로 적습니다.

| 키 | 내용 |
|---|---|
| `neul-clean` | 휴지통 자동 비우기 일수 (기본 30, 0이면 안 지움) |
| `neul-duprules2`, `neul-dupmode`, `neul-dupo-*`, `neul-dupg-*` | 같은 책(중복) 찾는 규칙과 방식 |
| `neul-awake` | 문서를 볼 때 화면 꺼짐 방지 |
| `neul-hlstraight` | 형광펜 직선화 (`'0'`이면 끔) |
| `neul-sort` | 서재 정렬 방식 |
| `neul-theme`, `neul-tpal`, `neul-night` | 테마(밝게/어둡게/자동), 색 팔레트, 야간 보기 |
| `neul-ttsrate` | 읽어 주기 속도 |
| `neul-vfcfg`, `neul-vfgain` | 음성 넘김 설정, 소리 크기 |
| `neul-bar`, `neul-pal-v3` | 상단바·도구 팔레트의 순서와 숨김 구성 |
| `neul-setst` | 위 설정을 바꾼 시각 기록(동기화용) |

## 2. 이 기기에서만 쓰는 설정 (동기화하지 않음)
| 키 | 내용 |
|---|---|
| `neul-finger` | 손가락으로도 필기 |
| `neul-qr` | QR 코드 눌러서 열기 (`'0'`이면 끔) |
| `neul-gmax` | PDF 자동 내려받기 최대 크기(MB, 기본 30, 0이면 제한 없음) |
| `neul-shelfcols`, `neul-thcols` | 서재 한 줄 권수, 쪽 목록 열 수 |
| `neul-mode` | 보기 방식(스크롤/쪽 넘김) |
| `neul-view-<카테고리>` | 카테고리별 "폴더별/전체" 보기 |
| `neul-exp` | 펼쳐 둔 카테고리 |
| `neul-penhijack` | 이 기기에서 펜 입력과 스크롤 겹침 보정을 쓰는지 |
| `neul-userpal`, `neul-tape`, `neul-shapefmt` | 직접 만든 색, 형광 테이프 설정, 도형 서식 |
| `neul-print`, `neul-more-v2` | 인쇄 설정, 더보기 메뉴 구성 |
| `neul-bibleurl` | 늘성경 주소 |

## 3. 화면 위치·접힘 (기기마다 다름)
도구 팔레트, 받아쓰기, 읽어 주기, 음성 넘김 단추의 위치·접힘 값입니다.
`neul-pal`(도구 팔레트 보이기), `neul-barpos`, `neul-barfold`, `neul-bartabx`, `neul-palpos`, `neul-palfab`, `neul-detpos`, `neul-detfab`, `neul-detfold`, `neul-ttspos`, `neul-ttsfab`, `neul-ttsfold`, `neul-ttsbarpos`, `neul-ttsmin`, `neul-vffab`, `neul-vftoolspos`, `neul-vfbarpos`, `neul-vfbarmin`, `neul-biblefold`
(이 중 일부 키의 앞부분 묶음은 코드의 `VIEW_PFX`, `VIEW_KEY`에 있습니다.)

## 4. 구글 드라이브 동기화·백업 상태
| 키 | 내용 |
|---|---|
| `neul-gsync` | 동기화 켜짐 |
| `neul-gblob` | PDF 원본도 동기화할지 |
| `neul-gtoken` | 로그인 토큰 (만료되면 지워짐) |
| `neul-gbak` | 드라이브 폴더 자동 백업 켜짐 (`'1'`이면 켜짐) |
| `neul-gtab` | 동기화 창에서 마지막에 본 탭(동기화/백업) |
| `neul-gtime` | 마지막 동기화 시각 |
| `neul-gdirty` | 올릴 변경이 남아 있는지 |
| `neul-ghint` | 로그인한 구글 계정(이메일) 표시용 힌트 |
| `neul-gbakq`, `neul-gbaknames`, `neul-gbakfid` | 드라이브 폴더 백업 대기열, 올린 이름 기록, 백업 폴더 id |

## 5. 같은 책(중복) 처리 기록
`neul-dupign`(무시한 묶음), `neul-dupnot`(다른 책으로 표시한 쌍), `neul-dupkeep`(남기기로 한 문서), `neul-duprules`(옛 버전의 규칙 — 새 규칙(duprules2, 1번 표)이 없을 때 옮겨 읽기만 함)

## 6. 받아쓰기
`neul-dictsess`(기록), `neul-dicttxt`(예전 형식의 글, 새 형식으로 옮김), `neul-dictdel`(지운 기록, 다른 기기에서도 지우기 위해 남김)

## 7. 그 밖
| 키 | 내용 |
|---|---|
| `neul-errlog` | 오류 기록 (설정 → 오류 기록) |
| `sessionStorage` `neul-dtabs` | 열어 둔 탭 목록 (탭을 닫으면 사라짐) |
| `sessionStorage` `neul-reloaded` | 새 버전으로 이미 한 번 새로고침했는지 |
| `sessionStorage` `neul-swr` | 서비스워커 교체 때 새로고침을 한 번만 하려는 표시 |
| 캐시 `neul-share` | 다른 앱에서 공유받은 파일 임시 보관 |

## 이름이 비슷하지만 저장 키가 아닌 것
- `neul-build:` : 새 버전 확인용 표식(코드 주석)
- `neul-item:` : 항목 복사·붙여넣기 때 클립보드에 넣는 글머리
- `neul-tmp-` : 드라이브에서 임시로 만드는 파일 이름
- `neul-hwp-` : 한글 창 이름

## 새 키를 만들 때
- 기기마다 달라도 되는 값이면 아무 설정도 하지 않아도 됩니다.
- 모든 기기에서 같아야 하는 설정이면 `setSyncKey` 정규식에 이름을 추가해야 합니다. 안 하면 기기끼리 따로 놉니다.
- 값을 읽고 쓸 때는 `lsGet`, `lsSet`을 쓰세요. 저장소를 못 쓰는 환경에서도 앱이 멈추지 않게 처리돼 있습니다.
