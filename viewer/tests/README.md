# 늘뷰어 자동 점검

앱을 고친 뒤 **올리기 전에** 컴퓨터에서 한 번 돌려 보는 점검입니다. (휴대폰·태블릿 실기기는 대신해 주지 않습니다)

## 준비 (처음 한 번)
```
cd viewer/tests
npm install
npx playwright install chromium
```

## 실행
```
npm test
```
- 마지막에 `통과 N / 실패 M`이 나오고, 실패가 있으면 종료 코드가 1입니다.
- 시험은 앱 폴더(`viewer/`)를 자체 서버로 띄워 실제 크롬(Chromium)에서 돌립니다.
- 인터넷 없이 돌도록 pdf.js·pdf-lib는 `node_modules`의 것을 쓰고, 한글 편집기는 가짜로 바꿔 끼웁니다
  (실제 편집기 화면은 점검하지 않습니다).

## 점검 항목
1. 시작할 때 오류가 없는지
2. `.hwp` 가져오기 → 서재에 '한글' 카드
3. 새 한글 문서 → 늘한글 탭 · 상단바 버튼 · 저장 → 문서로 열기(글자 층 포함)
4. 문서 상단바 '늘한글로 편집' → 탭 2개로 오가기
5. 한글 원본 내려받기
6. 글상자: 줄바꿈 · `- ` 입력 · 방향키가 커서만 움직이는지
7. 받아쓰기 창 접기/펼치기
8. 받아쓰기 중복 줄 합치기(같은 문장을 조금씩 바꿔 다시 보내는 경우)
9. 오류 기록 화면 · 오류가 기록되는지

## 새 시험 넣기
`e2e.cjs`의 `test('이름', async ctx => { ... })` 한 덩어리를 추가하면 됩니다.
버그를 고칠 때는 **그 버그를 재현하는 시험을 먼저** 넣어 두면 같은 사고가 반복되지 않습니다.

## 환경 변수
- `PWDEBUG`가 아니라 `HEADED=1`을 주면 브라우저 창을 띄웁니다.
